# EventLink

Discover Opportunities. Build Your Future.

EventLink is an AI-powered opportunity discovery platform connecting students, graduates, and professionals with jobs, internships, scholarships, hackathons, events, and career opportunities.

## Technology Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- Version Control: Git + GitHub

## Project Structure

- apps/web: React frontend
- services/backend: Node.js backend
- shared: Shared constants and validation
- docs: Project documentation

## Team Collaboration

We use Git feature branches and pull requests.

## Mission

To make opportunities easier to discover and access.
